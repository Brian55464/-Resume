資料流EXPOSURE PIPELINE
  1. INPUT相機讀值CameraX / Camera2
  2. CONTEXTEV 100 + ISO拍攝意圖・器材規格
  3. LOGIC曝光核心換算・刻度・條件判斷
  4. OUTPUT建議與紀錄Compose / 本機儲存

設計取捨

未知 ISO 與相機規格保留為 null。通用參考與相機實際可用刻度分開，避免產生看似可用的虛構設定。

驗證與限制

核心計算檢查、獨立 Android QA 與模擬器操作驗證。手機測光與 AR 估距精度仍需實機對照。

查看曝光組合的判斷方式 ＋

遍歷相機快門刻度，尋找最接近讀值的曝光組合；只保留誤差在半格內的結果。以下節錄自曝光核心：

double difference = ev100 - ExposureEngine.exposureEV(aperture, shutter, iso);
if (Math.abs(difference) < bestError) {
    bestError = Math.abs(difference);
    bestTime = shutter;
}
