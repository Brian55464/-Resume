# 黃博章 Bozhang Huang — Portfolio

[查看作品集](https://brian55464.github.io/-Resume/)

資訊管理研究生的工程作品集，以深藍、暖白與黃色為主。首頁點擊空白或圖形區域可切換三種參數曲面，並提供鍵盤按鈕；互動只作用於首頁區塊。專案區包含操作畫面、功能摘要與作品入口，技術筆記則呈現資料流、設計取捨與驗證範圍。

## 作品

- **片刻 Filmwise 0.4.0**：完整介紹、網頁曝光試算、Android 正式版 APK、整理過的原始碼 ZIP。
- **金鳳出航**：完整沉浸式行銷網站、原始碼 ZIP。
- **LINE 個人 AI Agent**：功能示意與架構說明，不含原始碼、私人設定、金鑰、行程或帳目。
- 保留 SKYLINE、PTT ETF Market Signal、大數據分析與社群分析入口。

## 結構

- `index.html`、`style.css`、`refinement.css`、`app.js`：作品集。
- `projects/filmwise/`：Filmwise 專案介紹與公式示範。
- `projects/coldchain/`：金鳳出航完整網站與素材。
- `assets/`：作品集圖像。
- `downloads/`：公開下載與 SHA-256 驗證碼。

不需要套件安裝或建置。以任意靜態網頁伺服器開啟，或透過 GitHub Pages 以 main 分支根目錄發布。

## 設計參考

以原網站深藍與黃色延伸個人識別，參考 [Brittany Chiang](https://brittanychiang.com/) 的工程經歷與專案組織方式，以及 [Lee Robinson](https://leerob.com/) 的簡潔自介與技術筆記結構。保留前期參考 [Dennis Snellenberg](https://dennissnellenberg.com/) 與 [Bruno Simon](https://bruno-simon.com/) 的互動節奏，重新設計版面與程式。未複製其程式碼、照片或素材。

動畫尊重系統減少動態效果設定，作品集右上角亦可切換。Filmwise 圖片為實際 App 示範畫面，網頁曝光試算不是即時測光。字型授權隨各專案提供。

作品集不提供 GitHub 個人頁或儲存庫連結。資料分析與社群分析作品改為站內展開介紹；聯絡區使用 Email 入口。
